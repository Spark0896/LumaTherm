## Фактическое состояние подсветки

После запуска выбран **NVML**, LampArray обнаружен. Runtime сообщает
**LightingWaiting**: Windows пока не предоставила управление подсветкой.
Температурный источник и интерфейс работают; физическое изменение цвета
и получение управления в текущем сеансе не подтверждены.

Принудительное переключение глобального Dynamic Lighting, перезапуск
служб/драйверов и перезагрузка не выполнялись. Автозапуск после следующей
загрузки ОС этой установкой не проверен.
