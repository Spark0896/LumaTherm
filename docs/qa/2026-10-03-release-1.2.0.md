## Evidence boundaries

These results distinguish automated tests, package/signature checks, and actual
installed-runtime observations. They do not establish a real Windows reboot/login,
sleep/resume, visual inspection of physical LEDs, clean-VM installation, or universal
RGB-device compatibility. Hardware remains limited to Windows LampArray devices.

Publication is verified separately against the GitHub release assets, checksums,
latest-release feed, and source tag after upload.
