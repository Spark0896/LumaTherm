# Установка

## Перед установкой

LumaTherm 1.2.1 поддерживает x64 Windows 11 (22H2 или новее), драйвер NVIDIA и совместимое устройство Windows Dynamic Lighting / LampArray. На чистой Windows 11 **не** нужны .NET, GCC и MSI Afterburner. Драйвер NVIDIA и подходящее LampArray-устройство обязательны. MSI Afterburner — только необязательный резервный источник температуры для чтения.

Загружайте setup и `SHA256SUMS.txt` только со страницы [GitHub Releases](https://github.com/Spark0896/LumaTherm/releases). Наличие исходного кода не означает, что финальный релиз уже опубликован.

## Проверка SHA-256

В папке загрузок выполните:

```powershell
Get-FileHash .\LumaTherm-1.2.1-win-x64-setup.exe -Algorithm SHA256
Get-Content .\SHA256SUMS.txt
```

Сравните шестнадцатеричный хэш со строкой `LumaTherm-1.2.1-win-x64-setup.exe`. При несовпадении остановитесь.

## Установка

1. Войдите в учётную запись администратора, в которой будете пользоваться LumaTherm, и дважды щёлкните `LumaTherm-1.2.1-win-x64-setup.exe` обычным способом. Подтвердите запрос Windows на повышение прав для этой же записи.
2. Прочитайте запрос сертификата. Этой локально подписанной сборке для регистрации Windows lighting identity нужно импортировать свой **публичный** сертификат в `LocalMachine\Root` («Доверенные корневые центры сертификации»). Закрытый ключ не импортируется. Отказ останавливает установку до замены файлов и регистрации.
3. При необходимости выберите ярлыки. Установщик запускает мониторинг в фоне от обычного пользователя Windows. Опция **Open LumaTherm** также открывает окно. Тихая установка запускает мониторинг в трее.
4. При новой установке совместимое устройство выбирается автоматически и термосинхронизация сразу включена. Установщик включает Dynamic Lighting, ставит LumaTherm первой для текущих и новых устройств и отключает перехват управления активными приложениями, чтобы синхронизация продолжалась при переключении окон. Эти параметры можно изменить через **«Настройки подсветки Windows»**.

Sparse identity подсветки и её параметры относятся к одному пользователю Windows. До замены файлов и импорта сертификата setup проверяет, что исходный пользователь без повышенных прав и пользователь после повышения имеют одинаковый SID. Обычная учётная запись с вводом пароля другого администратора не поддерживается. Запуск из уже повышенного процесса (включая **«Запуск от имени администратора»**), сеанс с отключённым UAC и полным токеном администратора, а также развёртывание от SYSTEM тоже отклоняются: исходного пользователя без повышенных прав нельзя установить. Запускайте setup обычным способом из нужной учётной записи администратора с включённым UAC. Тихая установка имеет те же ограничения; `/ALLOWCERTIMPORT` разрешает только импорт сертификата и не обходит проверку пользователя или повышение прав Windows. Удаляйте приложение из той же учётной записи.

Установщик проверяет результат и локально сохраняет прежние параметры. При удалении восстанавливаются значения, которые всё ещё соответствуют настройке установщика; более позднее изменение порядка пользователем сохраняется. Неизвестный формат параметров Windows вызывает явную ошибку установки.

Установщик сохраняет положительные значения яркости и поднимает явно заданную нулевую яркость до 50%. Затем он проверяет отправку цвета из обычного сеанса пользователя Windows. Если Windows всё ещё не предоставляет управление, установщик предлагает перезапустить систему. Отсутствие оборудования и выключенная в сохранённых настройках синхронизация отображаются в журнале установки. Проверка подтверждает отправку команды Windows. Фактическое свечение зависит от устройства и прошивки.

При новой установке **«Запускать с Windows»** включён. При обновлении сохранённые
настройки сохраняются. В
установленной версии он управляет системной задачей автозапуска; Windows также
показывает её в разделе **Параметры → Приложения → Автозагрузка**. При
автозапуске LumaTherm работает в фоне, поэтому оставьте включённым хотя бы один
пункт меню в трее, чтобы окно было удобно открыть снова.

При удалении деинсталлятор снимает только точную identity LumaTherm и удаляет точный сертификат из комплекта. Отдельно он спросит об удалении настроек и журналов `%LOCALAPPDATA%\LumaTherm`.

Для установки в выбранную папку используйте [portable](portable.ru.md).
