# Установка

## Перед установкой

LumaTherm 1.1.0 поддерживает x64 Windows 11 (22H2 или новее), драйвер NVIDIA и совместимое устройство Windows Dynamic Lighting / LampArray. На чистой Windows 11 **не** нужны .NET, GCC и MSI Afterburner. Драйвер NVIDIA и подходящее LampArray-устройство обязательны. MSI Afterburner — только необязательный резервный источник температуры для чтения.

Загружайте setup и `SHA256SUMS.txt` только со страницы [GitHub Releases](https://github.com/Spark0896/LumaTherm/releases). Наличие исходного кода не означает, что финальный релиз уже опубликован.

## Проверка SHA-256

В папке загрузок выполните:

```powershell
Get-FileHash .\LumaTherm-1.1.0-win-x64-setup.exe -Algorithm SHA256
Get-Content .\SHA256SUMS.txt
```

Сравните шестнадцатеричный хэш со строкой `LumaTherm-1.1.0-win-x64-setup.exe`. При несовпадении остановитесь.

## Установка

1. Запустите `LumaTherm-1.1.0-win-x64-setup.exe` от имени администратора.
2. Прочитайте запрос сертификата. Для регистрации Windows lighting identity установщик должен импортировать свой **публичный** сертификат в `LocalMachine\TrustedPeople`. Отказ останавливает установку до замены файлов и регистрации.
3. При необходимости выберите ярлыки. Пункта запуска после установки нет, приложение не запускается автоматически.
4. Запустите LumaTherm через меню «Пуск» или ярлык, выберите Windows LampArray и не включайте термосинхронизацию до доступности устройства.

При удалении деинсталлятор снимает только точную identity LumaTherm. Отдельно он спросит об удалении настроек и журналов `%LOCALAPPDATA%\LumaTherm`.

Для переносимой папки используйте [portable](portable.ru.md).
