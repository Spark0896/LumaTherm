# LumaTherm 1.1.0 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Выпустить LumaTherm 1.1.0 с неограниченным многоточечным температурным градиентом, интерактивным тестом реальной подсветки, RU/EN-интерфейсом, настраиваемым треем, проверкой GitHub Releases и полноценными installer/portable-дистрибутивами.

**Architecture:** Core получает неизменяемую многоточечную модель и отдельные контракты сохранения предпочтений и аппаратного теста. WPF использует общий интерактивный редактор профиля, динамические языковые ресурсы и изолированные сервисы трея/обновлений. Inno Setup устанавливает self-contained приложение в выбранную папку и регистрирует sparse MSIX identity, а portable использует ту же identity через отдельный помощник.

**Tech Stack:** C# 12, .NET 8, WPF, Windows Forms NotifyIcon, Windows Dynamic Lighting LampArray, NVIDIA NVML, System.Text.Json, xUnit v3, PowerShell, Inno Setup 6, GitHub Releases.

**Spec:** `docs/superpowers/specs/2026-08-22-lumatherm-1.1.0-design.md`

## Global Constraints

- Поддержка: Windows 11 `10.0.22621.0+`, x64, self-contained .NET 8.
- Основной датчик: NVIDIA NVML; MSI Afterburner shared memory остаётся необязательным read-only fallback.
- Единственный RGB write path: `Windows.Devices.Lights.LampArray`; GCC, vendor DLL и raw HID не используются.
- Ambient/background lighting требует `com.microsoft.windows.lighting` и пакетную identity.
- Настройки 1.0.1 мигрируют без потери цветов, температур, поведения и статуса режима.
- По умолчанию три насыщенные точки; пользовательское количество точек не имеет фиксированного максимума, минимум — две.
- Температуры: 0–120°C, расстояние соседей не менее 1°C; сглаживание: 0.1–5.0 с.
- Автозапуск по умолчанию выключен; сохранение предпочтений не меняет активность терморежима.
- Язык по умолчанию системный с английским fallback; ручные варианты — русский и English.
- Проверка обновлений только ручная; приложение не скачивает и не запускает обновление скрытно.
- Лицензия: MIT, copyright `2026 Spark0896`.
- Все production-изменения проходят red → green → refactor; документация меняется вместе с поведением.
- Команды .NET запускаются через `.dotnet/dotnet.exe` с `-p:NuGetAudit=false`.
