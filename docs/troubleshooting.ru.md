# Устранение неполадок

## Нет температуры GPU

Проверьте драйвер NVIDIA. В исходном checkout с установленным SDK из `global.json` выполните из корня репозитория проверку только для чтения (можно также использовать локальный `.dotnet\dotnet.exe`):

```powershell
dotnet run --project tools\LumaTherm.Smoke -c Release -- sensor --json
```

Если NVML недоступен, приложение может использовать shared memory MSI Afterburner. Запустите MSI Afterburner и включите shared-memory interface, если хотите использовать этот резервный источник. Читатель проверяет Unix-время опроса из заголовка источника и отклоняет данные старше пяти секунд; задайте интервал опроса не более пяти секунд. Доступность общей памяти сама по себе не подтверждает свежесть температуры. Ошибка резервного источника не является поводом устанавливать стороннее ПО подсветки или выполнять аппаратные записи.

## Нет LampArray или подсветка недоступна

Включите Windows Dynamic Lighting и выполните проверку только для чтения:

```powershell
dotnet run --project tools\LumaTherm.Smoke -c Release -- lights --json
```

Поставьте LumaTherm выше конфликтующих контроллеров. Если открыт GIGABYTE Control Center, закройте только страницу RGB Fusion и повторите поиск. Устройство, которое Windows вообще не показывает как LampArray, не входит в поддерживаемый контракт вывода. Если оно найдено с `available: false`, статус **«Ожидание управления подсветкой Windows»** означает, что Windows ещё не предоставила управление: устройство обнаружено, приложение ожидает его возврата. Перезапуск приложения или запись приоритета в реестр сами по себе не подтверждают получение управления в текущем сеансе.

## Ошибка setup или регистрации portable

Проверьте SHA-256 релиза и внутренний `SHA256SUMS.txt` portable-архива. Запускайте setup обычным способом из нужной учётной записи администратора и подтверждайте повышение для неё же; уже повышенный запуск и данные другого администратора отклоняются до изменений. Для регистрации portable повышайте PowerShell для этой же нужной записи, не меняйте распакованную папку и явно подтвердите импорт публичного сертификата. Несовпадение подписи/хэша, отсутствие прав администратора, отказ в запросе или перемещение portable-папки — намеренная остановка. См. [установку](installation.ru.md) и [portable](portable.ru.md).

## Приложение закрывается или не сохраняет настройки

Проверьте `%LOCALAPPDATA%\LumaTherm\logs`. Повреждённые настройки изолируются, затем применяются безопасные значения восстановления: терморежим и автозапуск выключены до ручного включения. Временная ошибка чтения или доступа останавливает запуск с ошибкой и сохраняет существующий файл; сначала устраните проблему доступа. При первом запуске без файла настроек терморежим и автозапуск включены. Не редактируйте `settings.json`, пока приложение запущено.

## Обновление

Используйте стабильный GitHub Release, проверяйте хэши и запускайте новый setup. Проверка обновлений читает только метаданные GitHub и открывает загрузку; скачивание и установка не выполняются автоматически. Для portable сначала снимите регистрацию, замените папку проверенным архивом и зарегистрируйте её снова.

## Автозапуск, трей и редактор профиля (текущие исходники)

«Запускать с Windows» применяется сразу. Если задача отключена пользователем в
Windows, откройте «Автозагрузка Windows» и разрешите LumaTherm. Задача, отключённая
политикой, требует изменения политики администратором. Зарегистрированную папку
portable нельзя перемещать.

При включённом сворачивании в трей кнопки сворачивания и закрытия скрывают окно.
Щелчок по значку трея возвращает окно; «Выход» в меню полностью завершает приложение.
Проверьте скрытые значки Windows, если значка не видно.

«Стандартные цвета» возвращает синий/зелёный/красный, сохраняя другие настройки.
Точки можно перетаскивать, менять стрелками, удалять Delete или кнопками редактора.
Исправьте температуру (0–120°C) и сглаживание (0,1–5 секунд) перед сохранением или
тестом. «Применить» сохраняет тестовый профиль; «Отмена» и закрытие окна завершают
временный тест и восстанавливают предыдущее состояние терморежима.
