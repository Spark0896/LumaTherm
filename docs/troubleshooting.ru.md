# Устранение неполадок

## Нет температуры GPU

Проверьте драйвер NVIDIA и выполните безопасную проверку только для чтения:

```powershell
& .\.dotnet\dotnet.exe run --project tools\LumaTherm.Smoke -c Release -- sensor --json
```

Если NVML недоступен, приложение может использовать shared memory MSI Afterburner. Запустите MSI Afterburner и включите shared-memory interface, если хотите использовать этот резервный источник. Ошибка резервного источника не является поводом устанавливать стороннее ПО подсветки или выполнять аппаратные записи.

## Нет LampArray или подсветка недоступна

Включите Windows Dynamic Lighting и выполните проверку только для чтения:

```powershell
& .\.dotnet\dotnet.exe run --project tools\LumaTherm.Smoke -c Release -- lights --json
```

Поставьте LumaTherm выше конфликтующих контроллеров. Если открыт GIGABYTE Control Center, закройте только страницу RGB Fusion и повторите поиск. Если Windows не показывает доступный LampArray, устройство не входит в поддерживаемый контракт вывода.

## Ошибка setup или регистрации portable

Проверьте SHA-256 релиза и внутренний `SHA256SUMS.txt` portable-архива. Для регистрации используйте повышенный PowerShell, не меняйте распакованную папку и явно подтвердите импорт публичного сертификата. Несовпадение подписи/хэша, отсутствие прав администратора, отказ в запросе или перемещение portable-папки — намеренная остановка. См. [portable](portable.ru.md).

## Приложение закрывается или не сохраняет настройки

Проверьте `%LOCALAPPDATA%\LumaTherm\logs`. Повреждённые настройки изолируются, а значения по умолчанию восстанавливаются, поэтому режим остаётся выключенным до ручного включения. Не редактируйте `settings.json`, пока приложение запущено.

## Обновление

Используйте стабильный GitHub Release, проверяйте хэши и запускайте новый setup. Проверка обновлений читает только метаданные GitHub и открывает загрузку; скачивание и установка не выполняются автоматически. Для portable сначала снимите регистрацию, замените папку проверенным архивом и зарегистрируйте её снова.
