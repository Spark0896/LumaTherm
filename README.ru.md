# LumaTherm

> [English](README.md) · Русский

LumaTherm меняет цвет совместимой подсветки Windows Dynamic Lighting по температуре GPU: холодный — синий, тёплый — жёлтый, горячий — красный. Сначала используется NVIDIA NVML; MSI Afterburner может быть резервным источником только для чтения общей памяти.

## Возможности

- плавный цветовой профиль с настраиваемыми точками температуры;
- мониторинг, история за 60 секунд, трей и необязательный автозапуск;
- английский, русский или системный язык интерфейса;
- прямое управление только через Windows LampArray — без vendor DLL и без низкоуровневых HID-записей;
- проверка стабильных релизов GitHub выполняется только когда пользователь вручную запускает проверку, без опроса при запуске или в фоне; приложение открывает страницу/загрузку релиза, но не скачивает и не устанавливает обновления само.

## Требования

Нужны Windows 11 (22H2 или новее), драйвер NVIDIA и совместимое устройство Windows Dynamic Lighting / LampArray. На чистой Windows 11 не требуются .NET Runtime, GCC или MSI Afterburner: приложение самодостаточно. MSI Afterburner нужен только для его необязательного резервного датчика. Устройство подсветки должно быть обнаружено Windows; совместимость с каждым RGB-устройством и ПО производителя не заявляется.

## Быстрый старт: установщик

1. Скачайте `LumaTherm-1.1.0-win-x64-setup.exe` и `SHA256SUMS.txt` со страницы [GitHub Releases](https://github.com/Spark0896/LumaTherm/releases).
2. Сверьте SHA-256 (см. [установку](docs/installation.ru.md#проверка-sha-256)).
3. Запустите установщик от имени администратора и явно согласитесь на импорт **публичного** сертификата. Это необходимо для регистрации Windows lighting identity; закрытый ключ не импортируется.
4. Откройте LumaTherm через ярлык, убедитесь, что режим выключен, выберите LampArray и включайте режим только после обнаружения устройства Windows.

Установщик не предлагает запуск приложения по завершении и не запускает его автоматически.

## Portable и регистрация

Portable-архив содержит самодостаточное приложение и разреженный пакет identity. Распакуйте его в постоянную папку, проверьте контрольные суммы и в повышенном PowerShell выполните `./install.ps1 -ConfirmCertificateImport`. Регистрация явная, требует доверия к сертификату и связывает identity с внешней папкой portable; не перемещайте её, пока identity зарегистрирована. Подробности: [portable](docs/portable.ru.md).

## Dynamic Lighting

Включите Dynamic Lighting в Windows и поставьте LumaTherm выше конфликтующих фоновых контроллеров. Если LampArray не обнаружен, закройте только страницу RGB Fusion в GIGABYTE Control Center (если она удерживает устройство), затем повторите поиск. LumaTherm не управляет, не останавливает и не исследует программы GIGABYTE.

## Конфиденциальность и обновления

LumaTherm хранит настройки и журналы локально в `%LOCALAPPDATA%\LumaTherm`. Проверка обновлений, запущенная вручную, запрашивает `https://api.github.com/repos/Spark0896/LumaTherm/releases/latest`; персональные данные не отправляются. При ошибке сети или если ответ не является опубликованным стабильным semver-релизом обновление не предлагается.
